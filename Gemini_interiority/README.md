# Gemini Interiority Inference

This directory contains the inference-only pipeline used to apply the selected
Gemini interiority classifier to prepared corpus passages. It does not use
human gold labels or calculate gold-label evaluation metrics.

See [INFERENCE_README.md](INFERENCE_README.md) for input requirements, commands,
authentication, checkpoint behavior, and outputs. Gold-label model evaluation
is documented separately in `../Gemini_evaluation/README.md`.
